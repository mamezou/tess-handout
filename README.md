# AWS Technical Essentials 受講者向け配布資料

研修のラボを早く終えた人向けの追加課題を置いています。ラボ本体の手順は研修ポータルのものを使い、こちらは補助資料として並べて読んでください。

## 使い方

- 各課題には「ゴール」「確認方法」「考えてみる」「ヒント」があります。まずヒントを見ずに取り組んでください
- ラボ環境は各ラボで独立しています。課題で設定を変えても、次のラボには影響しません
- ラボのアカウントは権限が絞られています。操作が拒否されたら、その課題は飛ばして次に進んでください
